A clean news magazine WordPress theme for headlines, categories, and editorial layouts.

== Description ==

Pressora is a lightweight news-category theme. It is built for newspapers, magazines, and editorial blogs.

The theme focuses on presentation only: header and footer layouts, featured stories, category labels, grid or list news layouts, Customizer colors, menus, and widget areas. Extra features such as custom post types, custom widgets, sharing buttons, and view counts can be added later with a plugin.
